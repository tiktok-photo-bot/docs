Первый конфиг

Перед началом работы с ботом вам потребуется создать конфигурацию. Процесс создания конфига простой и интуитивно понятный, но требует внимания к обязательным полям.

Создание конфига занимает несколько шагов. Обратите внимание на следующие требования:

  • TikTok-ссылка — обязательное поле.
    Укажите ссылку на свой профиль TikTok. Именно из этого профиля бот будет брать видео для комментинга. Перед этим на забудьте сделать ропсты видео под которыми бот должен отствлять комментарии.
Пример ссылки

https://www.tiktok.com/@username

  • Название конфига — обязательное поле.

  • Никнейм(username) — опциональное поле.
    Укажите никнейм который будет использоваться на аккаунте с которого бот будет оставлять комментарии. Не указывайте спец. символы которые не поддерживает TikTok, эмоджи в никнейме. В противном случае никнейм просто не будет устанавливаться. То же самое относится и к Био.

  • Био — опциональное поле.
    Описание которое который будет использоваться на аккаунте с которого бот будет оставлять комментарии.

  • Аватар — опциональное поле.
    Отправьте фото профиля, которое будет использоваться на аккаунте с которого бот будет оставлять комментарии.

  • Фото — обязательное поле.
    При создании конфига необходимо загрузить фото, которое будет отправляться в коментариях. Очень ВАЖНО проверить, что фото не тенит в комментариях.

  • 📈 Буст (лайки/комментарии) — настраивается отдельно.
    Услуги буста (APISeller или Heysmmseller) подключаются не в самом конфиге, а в специальном меню «📈 Буст». После настройки буст можно прикрепить к любому созданному конфигу.
